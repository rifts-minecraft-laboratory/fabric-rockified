# Rockified

If you ever wondered why blocks made of rock didn't actually drop rock when they were broken, this mod is made for you. Rockified allows blocks such as stoned ores to drop cobblestone when they are broken. It works with deepslated ores and netherracked ores.

## Technical aspect

Rockified was developed with Love thanks to the Fabric mod launcher. No additional features as planned, but if Mojang / Microsoft decide to add new kinds of rocked ores (or anything similar), Rockified will consequently get an update. The purpose is to make Minecraft a bit more realistic; We thought it was a shame to not drop an actual rock when a rocked block was getting broken.
